# Public Fixtures

This directory is for non-private `.docx` inputs that are safe to version. Fixtures
should contain only synthetic or explicitly public content. When generated by Microsoft
Word or another editor, document properties must be inspected and sanitized before
commit so local usernames, paths, tenant names, or customer data are not stored.

`word-smoke.docx` was generated with Microsoft Word from synthetic text and then had
core document properties rewritten to neutral values.
